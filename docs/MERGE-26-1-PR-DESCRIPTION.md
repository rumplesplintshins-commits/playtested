# Merge 26.1 — Performance & UX Optimisation

The live anonymous catalogue can hit statement timeouts, repeated pagination refetches public data, screenshot saves lose the developer's position, and legacy long titles crowd mobile administration. This change adds parameter-sensitive catalogue planning, bounded anonymous tab-memory caching/prefetch, parallel independent reads/transfers, upload progress and scroll preservation, 60-character new/changed title validation with legacy compatibility, responsive review/notification layouts, all-time developer game metrics and collapsed XP guidance with separate UK timestamps.

Based on `v11` at `1c85227`; Merge 27 remains independent. Migrations 128–131 are development-tested only. Migration 128 recognizes the direct production fixture-guard hotfix and refuses unknown definitions. Existing invoker/RLS, origin/auth/ownership checks, Featured ranking, fixtures/NSFW exclusions, deduplication and counts are retained. No production merge, deployment, migration, seed import or environment change is part of this PR.

Validation: TypeScript and final production build pass; focused SQL/API/security, original screenshot/origin/developer-edit, PC/reservation/privacy/notification regressions pass. Browser tests cover pages 1–7, cache/stale/debounce/prefetch/data-saving, screenshot replacement/removal/failure/scroll, title counter, keyboard disclosure, timestamps and mobile admin/notification layouts. Targeted lint introduces no additional error-rule counts; 11 baseline errors remain in changed files.

Measurements: live baseline includes HTTP 500/57014 and ~3.1s RPCs. Native development PostgreSQL with 195,362 rollback-only imports/9,550 eligible and five warm samples improved median 452.961 → 410.687ms (~9.3%); another run showed ~6.6%. PGlite showed no improvement. Local cached revisits were 62–78ms and correction reads started simultaneously rather than ~197ms apart. Mocked screenshot UI timings do not establish throughput improvement. These results do not prove the live first-load target.

Before release: owner review, fresh database AND Storage recovery verification, guarded migration preflight/order, controlled Render deployment and actual live timings/smoke checks. Actual toolbar zoom, screen-reader and real-upload acceptance remain pending. See `docs/MERGE-26-1-DEPLOYMENT-CHECKLIST.md`, `docs/MERGE-26-1-VALIDATION.md`, `MERGE-26-1-PROGRESS.md` and `docs/performance/` for evidence and rollback details.

Changed areas: `GameCatalogue`, public cache; `SubmissionCorrection`/submit/completeness/title hints; `ScreenshotManager`/media API/developer save; admin review/metrics, notification bell, listing controls, feedback queue/UK formatting; four migrations; focused tests/benchmark scripts and release documentation.
